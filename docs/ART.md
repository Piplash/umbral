# Recursos y procedencia

Dos atlas originales creados con la herramienta integrada `image_gen` para este proyecto, usando la imagen adjunta del usuario exclusivamente como referencia de estilo. No se descargaron recursos de videojuegos comerciales ni paquetes externos. La imagen de referencia se conserva por separado y no se carga durante el juego.

- `assets/art/environment.png`: atlas RGBA de 1254×1254, cuadrícula 4×4. Primera fila: cuatro suelos. Filas restantes: doce objetos reutilizables. El primer resultado conservaba un fondo cuadriculado; se corrigió con una segunda llamada de edición para obtener transparencia real en esas filas. El original de generación queda en la carpeta de imágenes de Codex; el proyecto contiene la versión corregida.
- `assets/art/characters.png`: atlas RGBA de 1254×1254, cinco columnas; sprites en la zona superior y retratos en la inferior. `ArtLibrary` define regiones normalizadas tras inspeccionar el resultado.
- Iconos, marcos y efectos: dibujo original de Godot mediante líneas, rectángulos y arcos, sin fuentes de emojis.
- Tipografía: SystemFont utiliza Georgia/Times New Roman instaladas en Windows y la fuente de respaldo de Godot; no se redistribuyen archivos tipográficos del sistema.
